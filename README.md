YouTube MP3 Downloader

A Firefox extension that allows users to download YouTube videos as MP3 files
directly from the YouTube interface or through a context menu option.


Features
- Download YouTube videos as MP3 files with a single click.
- Context menu option for downloading MP3s from YouTube links.
- User-friendly interface integrated into YouTube pages.
- Customizable download options (file name, folder location).
- High-quality audio extraction.
